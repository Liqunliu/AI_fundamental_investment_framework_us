# Standalone Qualitative Analysis — Coordinator

> Entry point for `/business-analysis` skill. Runs the shared qualitative assessment
> as a standalone analysis without requiring a full strategy (QY/Cigar/Cyclical) context.
>
> This coordinator handles data collection and dispatches the qualitative assessment module.

---

## Input Parsing

User input:

| Input | Example | Required? |
|-------|---------|-----------|
| Ticker symbol | `MSFT`, `AAPL` | YES (exactly 1 ticker) |
| Data source | `--source bloomberg` or `--source yfinance` | Optional (default: yfinance) |

**Parsing rules**:
1. Extract single ticker symbol (1-5 uppercase letters)
2. Extract `--source` flag if present
3. Default source: `yfinance`
4. If multiple tickers provided, analyze one at a time sequentially

---

## Execution Pipeline

### Task 1: Data Collection (Budget: 5 min)

```bash
# yfinance (default):
python3 scripts/yfinance_collector.py --ticker {TICKER} --output output/{TICKER}/data_pack.md

# Bloomberg (if --source bloomberg):
python3 scripts/bloomberg_collector.py --security "{TICKER} US Equity" --output output/{TICKER}/data_pack.md
```

**Verify**: `output/{TICKER}/data_pack.md` exists and contains §1-§8, §11-§12

**Skip data collection if**: `output/{TICKER}/data_pack.md` already exists and was created
within the last 7 days. Inform the user that existing data is being reused.

### Task 2: Qualitative Assessment (Budget: 8 min)

1. **Load** the qualitative assessment framework:
   ```
   Read("prompts/shared/qualitative/qualitative_assessment.md")
   ```

2. **Load reference files as needed**:
   ```
   Read("prompts/shared/qualitative/references/framework_guide.md")     — for D2 moat analysis
   Read("prompts/shared/qualitative/references/framework_scope.md")    — for applicability & limitations
   Read("prompts/shared/qualitative/references/market_rules_us.md")     — for US-specific rules
   Read("prompts/shared/qualitative/references/judgment_examples.md")   — for calibration
   Read("prompts/shared/qualitative/references/output_schema.md")       — for output format
   ```

3. **Read data pack**:
   ```
   Read("output/{TICKER}/data_pack.md")
   ```

4. **Execute** the full qualitative assessment (Pre-Analysis + D1-D6)

5. **Write output**:
   ```
   Write("output/{TICKER}/qualitative_report.md")
   ```

### Task 3: Output Delivery

Present to user:

1. **Summary card**:
```markdown
## {TICKER} — Qualitative Assessment

| Dimension | Rating | Key Finding |
|-----------|--------|-------------|
| D1: Business Model | [type] | [one sentence] |
| D2: Moat | [WIDE/NARROW/NONE] | [one sentence] |
| D3: Environment | [cyclicality] + [regulatory] | [one sentence] |
| D4: Management | [rating] | [one sentence] |
| D5: MD&A | [credibility] | [one sentence] |
| D6: Structure | [applicable/N/A] | [one sentence] |

**Overall Quality**: [A/B/C/D]
**Conclusion**: [PASS / VETO (reason)]
```

2. **Full report location**: `output/{TICKER}/qualitative_report.md`

3. **Strategy recommendations** (if applicable):
   - If quality A/B → "Consider full Quality Yield analysis: `/us-qy {TICKER}`"
   - If capital-hungry + cyclical → "Consider Cyclical analysis: `/us-cycle {TICKER}`"
   - If low P/B + deep value → "Consider Cigar Butt analysis: `/us-cigar {TICKER}`"

## Error Handling

- If data collection fails → report error, do not proceed
- If key data sections missing (§3/§4/§5) → proceed with available data, flag gaps
- If ticker is not US-listed → warn user, proceed if data is available
